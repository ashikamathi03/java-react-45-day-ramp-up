# 1. How 2D Array works:
### Step 1:The Grid Layout
#### **Row 1**-->[78 | 92 | 65]
#### **Row 2**-->[45 | 51 |60 ]
#### **Row 3**-->[88 | 90 | 95]
# 2.How to Access the Elements inside the array:
### Access Elements by the rows and columns
**marks[0][0]** = **78**

**marks[0][1]** = **92**

**marks[1][2]** = **60**

**marks[2][0]** = **88**

## Rule: 
Always specify the row first and then the column.

### Step 2:Loops

##### Outer Loop:
The outer loop [i] steps through each row.

The Inner loop [j] steps through each column inside that row.
